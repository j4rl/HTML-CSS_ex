## How to use this repository

- Read each topic, then copy the examples into small `.html` and `.css` files to test them in a browser.
- Use the exercises after each group of topics instead of only reading passively.
- Prefer semantic HTML first, then add CSS for layout and visual design.
- Validate HTML with the W3C validator and inspect CSS/layout with browser developer tools.
